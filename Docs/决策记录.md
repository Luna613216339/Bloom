## 2026-11-02 第一段试玩反馈（用户定）

- **喜欢「动态 + 静态」组合**：第 7 关闸那种一队在走的球、加一团不动的球。以后多做这一类。
- **静止球群不能完全静止，要有 idle**：小幅地动（上下、左右、旋转、呼吸都可以探索），但**不能改变通关策略**。幅度要比连锁够得着的距离小得多。
- **分裂球 + 门的关有难度、不可或缺，但要更多引导**，而且要想清楚放在难度曲线的哪里，别让玩家直接退游。
- **美术改成白模**：现在太花、太潦草。先做干净的白模，配色用最简单的，不要五颜六色。用户探索好美术风格后，再盖在白模上面。目标是更精致、没锯齿（怀疑是没描边）。
- **美术效果图要联合 GPT 出**（Codex CLI 带图像生成）。
- **关卡要更多备选**，从多的里面挑。用户反馈慢，下一阶段可以让 Fable 自己长时间摸索。

## 2026-11-01 关卡扩展这轮的方向（用户定）

- **目标是游戏更好玩，不是展示造关管线。** 用户在真实项目里做过数据调难度，不需要在作品里再证明；这么小的项目套工业化流程没有意义。批量生成关卡可以有，但不是必须。
- **至少 20 关**，总数和结构由 Fable 定。每关形状一眼可辨、各有亮点，难度曲线有起伏、有理由。
- **亮点重点：解谜顿悟、画面奇观、时机操作。** 放松关要有，但不是重点：试玩 Demo 时体会不到节奏变化，而且平庸的放松关容易做，有解谜难度的关才值得花力气。
- **新机制先做样关试玩，通过了再铺进关卡。**
- **分裂球**：被波及后裂成两颗继续移动、也能引爆别的球。外观做成五彩球。
- **续命**：花金币买一次额外点击，正式关卡和无尽模式都能用，正式关卡更贵。定价以后再说。
- **试玩方式**：Unity 编辑器里按 Play，从主菜单选关。这轮不打网页版。
- **美术**：用户嫌球潦草、有锯齿，想以后做漂亮，这轮不碰。
- **文档进 Bloom 的 git，可以正常上 GitHub。** 取代 2026-08-02「干净版不放过程文档」的做法。提交里不要出现 Claude 署名。
- **工作分支可以推到 GitHub**，合并到 `main` 由用户点头。

## 2026-11-02 关卡扩展第一段的技术与规则决定（Fable 定，纯技术）

- **关卡是代码里的数据表，不再是场景。** `LevelCatalog.cs` 每关一个方法，写墙、门、笼子、蛇、摆好的球、随机散布；`LevelBuilder` 运行时搭进唯一的 `Level` 场景。理由：20 多关手摆场景造得慢、改不动，而且总览图和自动测试都要能读到关卡数据。旧 1-5 / 6-10 的场景文件已删除（git 里能找回），旧 6-10 关的几何从场景 YAML 原样抄进数据表。
- **解谜关布局固定**：摆好的坐标或固定随机种子。散布喘息关（1、4、9）保留每次随机。
- **分裂球的规则**：被任何火碰到就炸（算 1 颗），裂出两颗火星，**背着火源**左右各偏 40° 飞，速度 4.5，烧 1.6 秒后自己小炸一下；火星碰到谁谁就着，会被墙和关着的门弹开；火星不算通关数、不吃别人的火。"背着火源飞"是故意的：同一颗五彩球，从左边点着火星往右飞，从右边点着往左飞 —— 这就是「同一个动作在不同局面下后果天差地别」。
- **硬球的规则**：要被两把**不同的**火各碰一次。同一把火贴着它多久都没用。点出来的圈、每颗烧着的球、每颗火星各算一把火。第一次碰只把壳敲掉（外观变普通球）。
- **联动门**：同组的门点一扇全翻转。它把"先把门都开好再点"变成"在飞行中切换"，不加新东西，只是让门和火星咬合。
- **续命**：正式关卡 60、无尽模式 30，占位价，一次尝试最多续一次。**解谜关（`Puzzle = true`）默认不给续命**，否则谜题被花钱绕过去；是不是维持这个默认，等用户拍板。无尽模式失败时本局金币先入账，再问续不续，续命之后再失败只把新增部分入账。
- **蛇遇到关着的门整队停下等**（`HoldWhenBlocked`）是新关卡的选项，旧关卡保持原来"撞到各自散开"的行为。屏幕边界墙改到 Ignore Raycast 层，蛇的探路射线不再把屏幕边界当成门。
- **验证方式**：打一个 macOS 包，无头跑真实游戏代码（`AutoTest.cs`，每帧固定 1/60 秒，结果可复现）。每关跑两类：脚本化的解法（确认过得去）和全屏 12×7 格点的"随手一点"（确认解谜关不会被瞎点过掉）。没有再写一份数学模拟器 —— 门、火星、硬球、逃跑球都用真实代码跑，不会和游戏对不上。旧的 `ChainSimulation.cs` 只给无尽模式的平衡测试用，没动。
- **编辑器便利**：编辑器里全部关卡默认可选（Tools → Bloom → Editor: All Levels Selectable 可关），每次 Play 自动重置后发 300 块测试钱，否则续命按钮永远按不起。都只在编辑器里生效。
- **主菜单每行 6 格**，格子数跟着关卡表走。样关的数字用斜体。
- **新中文文案只用子集字体里已有的字**（续命按钮是「再打一下」），因为手上没有完整的 Noto Sans SC，重新生成字体要下载，属于要问用户的事。关卡名因此暂时不显示在游戏里。
