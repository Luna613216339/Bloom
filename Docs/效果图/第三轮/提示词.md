# 第三轮效果图任务（给 Codex / GPT）：界面 + 无尽模式皮肤

你在给一个 2D 连锁反应小游戏 Bloom 画美术效果图。玩法：玩家点一下，一颗球膨胀，碰到的球也被引爆膨胀，再去碰下一颗；场上有可以开关的门。
前两轮已经定了美术方向，这一轮画**界面**和**无尽模式的皮肤**。

## 必须遵守的审美（用户定的）
- 方向是附带的参考图 `../04.png` 和 `../第二轮/07.png`（极简几何）：平涂、干净、流畅、大片留白，有一点剪纸动画的流畅感。
- **纯白或接近白的底色**。绝不能有深色背景、霓虹、发光、辉光、玻璃、渐变光晕。
- 球必须是**完美的圆**，不要叶子、纹理、毛毡、陶土、纸纤维。
- 正式关卡里普通球是一种中灰，只有特殊球带颜色（发射球朱红、逃跑球蓝、硬球墨绿、分裂球五彩），参考 `../第二轮/11.png`。
- 界面元素也是极简几何：细线、正圆、圆角矩形、大留白，不要拟物按钮、不要阴影堆叠。
- 界面上的字只用很短的英文（如 Bloom、Level 12、Retry、Next、Endless、Shop），字少、字小、无衬线。不要水印。

## 要出的图（16:9 横版，各存一张 PNG）
存到 `Docs/效果图/第三轮/`，文件名 `15.png`–`22.png`，最后写 `说明.md`，每张一句话说明。

界面（五张）：
- 15 标题画面：大片白底，Bloom 字样，几颗灰球和一颗朱红球构成一点点画面，两三个入口（Play / Endless / Shop）。
- 16 选关界面：章节式，一屏一个章节，36 关分成 5–6 章。每关一个小圆或小格，显示关号；已过、未过、锁住三种状态一眼可分。
- 17 关卡内画面：一关正在玩的样子（球、门），界面元素尽量少：左上关号和关卡名，右上剩余点击数，一个暂停按钮。
- 18 过关结算：关卡画面淡出后，中间简洁地出现「通过」的状态和 Next / Retry 两个按钮。不要星星、不要分数排行。
- 19 暂停 / 设置：半透明白色盖在关卡上，音量、语言（中 / EN）、返回选关。

无尽模式的皮肤（三张，都是白底，同一个无尽模式画面，只换球的配色）：
- 20 墨色：普通球是深浅不一的墨黑、炭灰，克制、像水墨点。
- 21 暖调：普通球是米色、陶土橘、浅棕一类的暖色，平涂，不要陶土质感。
- 22 彩色：普通球是一组柔和、饱和度不高的多色（像糖果但不艳），仍然平涂、干净。
