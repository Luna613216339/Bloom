# 美术方案（2026-11-18）

给用户按项审美术用的一整套方案。**入口是 `审核报告.html`**（双击打开，不用联网）：每项 A / B / C 三个方案，点字母选，页面最下面自动拼出回复。

## 文件夹

- `01-全局基调/`：1.1 配色、1.2 层次感、1.3 线条和形状
- `02-元素造型/`：2.1 逃跑球、2.2 硬球、2.3 分裂球、2.4 火星、2.5 墙和笼子、2.6 门、2.7 辅助线
- `03-动画/`：3.1 点击圈、3.2 球的消失、3.3 逃跑、3.4 碎壳、3.5 火星、3.6 门、3.7 开场 / 过关 / 失败
- `04-界面/`：4.1 局内界面和字体、4.2 标题页、4.3 选关、4.4 过关和失败、4.5 暂停
- 每项下面一个方案一个文件夹（`A-名字/`），里面的文件名是关卡名。一、二、四是 GPT 画的效果图（JPG，旁边的 `提示词.txt` 是当时实际用的提示词）；三是游戏里实做、自动测试包录的 GIF。
- `参考/`：给 GPT 当布局依据的游戏截图。`提示词/`：每个方案的任务说明和清单。`工具/`：下面这些脚本。

## 怎么重出

都在工程根目录运行。

- 方案是什么、用哪几关、推荐哪个：改 `工具/schemes.py`（一、二、三）和 `工具/ui.py`（四）。报告和提示词都读这两份。
- 重出效果图：`python3 Docs/美术方案/工具/gen_prompts.py`（或 `gen_ui_prompts.py`）生成任务说明，再 `python3 Docs/美术方案/工具/run_all.py 6 [项的前缀]` 并行调 Codex（`gpt-6.1-sol` + `high`）。已经出齐的方案自动跳过，想重画就先删掉那个方案文件夹里的图。一个方案三张图大约用 5 小时额度的 3%。
- 重录动图：先打自动测试包，再 `python3 Docs/美术方案/工具/films.py [项的前缀]`。它给每个方案开一个进程，带 `-look skin=1,<项>=<A|B|C>`。
- 重新生成报告：`python3 Docs/美术方案/工具/build_report.py`（顺带把新出的 PNG 压成 JPG）。

## 动画方案在代码里的位置

`Assets/Scripts/Look.cs` 里九个开关（`ClickFx`、`PopFx`、`FleeFx`、`CrackFx`、`SparkFx`、`DoorFx`、`IntroFx`、`WinFx`、`FailFx`），默认都是 A（原来的样子）。
B、C 的画法在 `Fx.cs`，门的三种造型在 `DoorSkin.cs`（只在基准皮 `Look.Skin` 下生效）。
用户选完以后：把选中的字母写成默认值，没选中的版本连同对应的函数删掉。
