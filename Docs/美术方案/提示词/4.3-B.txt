省额度：只看本任务点名的图片，不要浏览别的目录，不要读任何文档和代码。

游戏规则一句话：玩家点一下，点出一个扩散圈；被碰到的球膨胀成圈、再去碰下一颗，连成链；目标是一次把全场球收完。门可以在连锁中途点击开关。

这一轮的做法：用户按"项"审美术，每一项有 A / B / C 三个方案，你只负责其中一个方案、下面列出的几张图。
【一次只改一个维度】是最重要的规矩：除了任务里"这个方案要改的"那一条，画面里其他所有东西都必须是下面的「暂定基准」，这样用户才能只比较这一个维度。不要顺手改进别的地方。

暂定基准：
- 底色：暖纸白 #F7F4EE，纯平，没有纹理、暗角、渐变。
- 普通球：墨青 #465A58 的实心正圆，全部同色同大小。
- 着火 / 扩散：朱红 #D9573F。着火的球是膨胀开的朱红实心圆；烧完的地方只留一圈很淡的细环。
- 墙、笼子：深墨 #37433F 的实心圆角粗条（宽约一颗球直径的 0.8 倍）。
- 门：关着 = 和墙一样宽的圆角条，颜色比墙浅一档（灰绿 #7C8985），正中一道底色细缝；开着 = 两片门叶各自缩回门洞两侧只露一小截，中间空着。
- 层次：每个实心形状（球、墙、笼子、门）正下方偏 3px 露出一片很淡的同形影子 #E7E1D6（平的剪影，边缘锐利，不模糊，不是投影光照）。
- 逃跑球：平涂蓝 #4A7FB0 的实心正圆。
- 硬球：墨绿 #2F6B57 实心圆芯，外面隔一道底色细缝套一圈同色细环（壳），整体外径和普通球一样。
- 分裂球：正圆里五道横向平涂色带（赭黄、珊瑚、灰绿、灰蓝、灰紫）。
- 瞄准线（分裂球的火星要飞的路）：浅灰绿 #B9C4BD 小圆点等距排成的点线。队伍路线：很淡的灰色发丝细实线。
- 界面（局内）：左上角"关号 + 英文关卡名"（小号细无衬线体，墨青色），右上角一个细线暂停圆钮。

- 浅色底。不要深色底、霓虹、发光、辉光、渐变。
- 球必须是完美的正圆、平涂。不要高光、纹理、材质（毛毡、陶土、水彩、玻璃）、叶子、果柄、表情。

- 构图、每颗球的位置和数量、墙和门的位置大小，都照参考图；不要挪动、增删、放大缩小、居中重排。

参考图有两种：
- 「基准图」：已经是暂定基准的样子。照它原样重画，只改任务说的那一个维度。
