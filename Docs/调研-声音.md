## 一、什么是好的音效（连锁反应 / 休闲解谜）

### 1. 音效要跟着连锁「往上走」
- **一步一个音、越走越高**：连锁第 1 颗球放音阶第 1 个音，第 2 颗放第 2 个音……玩家不用看分数，光听就知道连锁在变长，越长越爽。
- **只用一个调里的音**：音高不是随便升，而是取同一个音阶的音（最省心的是五声音阶，比如 C D E G A，怎么叠都不难听）。几十个音同时响也像一串和弦，不像噪音。
- **封顶**：升两个八度左右就停在最高音，或者回到低音再起一轮，不要无限升到刺耳。
- **用采样变调还是用代码合成**：同一个采样升降超过半个八度左右，音色会变尖、变闷（「花栗鼠声」）。要么备高、中、低 2–3 个采样分段用，要么直接用代码合成（音色在任何音高都一样）。
- **连锁结束给一个收尾音**：最后一颗消失时放一个稍长的和弦或泛音，告诉玩家「这一下结束了」。过关 / 没过关各一个短乐句。

### 2. 几十颗一起爆也不吵
- **限制同时发声数**：同一种音效最多同时 6–8 个，超出的直接不放，或者顶掉最老的那个。
- **同一帧合并**：同一帧（或 30–50 ms 内）触发的多颗球只放一个音、音量稍大，或者像下面 Mini Metro 那样把它们错开一点点排着放。
- **叠得越多，每个越轻**：同时在响 n 个时，每个音量乘 1/√n 左右，总响度不爆。
- **细微随机**：音量 ±10%、起音时间错开几毫秒、准备 2–4 个略有不同的采样轮流用（round-robin），听起来就不机械。**音高不要随机**，会把音阶打乱；最多加几音分的抖动。
- **压低背景音乐（ducking）**：大连锁时 BGM 自动降 3–6 dB，结束后在半秒到一秒内慢慢回来。
- **音色要软**：Bloom 是「轻轻消失」，适合起音快、尾巴短、没有噪声爆破成分的音：拨弦、马林巴、卡林巴、玻璃钟、柔和的正弦「啵」。别用爆炸、火、电流声。

### 3. 音效和 BGM 要在同一个调
- 先定 BGM 的调和速度（比如 D 大调、72 BPM），音效的音阶就从这个调里取。
- **最稳的做法**：BGM 用和弦变化很少的氛围铺底（pad / 持续音），这样音效的五声音阶在任何时候都不打架。和弦变化多的 BGM，音效就得跟着和弦换音阶（Peggle 就是这么做的，见下），实现复杂得多。
- **时间上要不要对拍**：可以把音效延迟到下一个 1/16 拍再响，更像音乐，但 72 BPM 下 1/16 拍约 0.2 秒，点击会显得迟钝。**建议只对音高、不对时间**；最多让「连锁收尾音」对拍。
- AI 生成的曲子不一定严格在你写的调上，拿到后要验一遍调（AI 可以用工具分析），不对就整体移调。

### 4. 几个知名游戏的做法（我的概括）
- **Peggle 系列**：球连续撞钉子，每撞一下沿音阶往上走一个音；音阶不是固定的，会跟着背景音乐当下的和声变，所以连撞几十下都和音乐合拍。开发者说「同一个音逐步升调」几乎不用加新素材就带来变化和兴奋感。
  来源：https://www.audiokinetic.com/zh/blog/peggle-blast-peg-hits-and-the-music-system 、https://www.audiogang.org/peggle2-sonic-joy/
- **Mini Metro**：几乎不分「音效」和「音乐」，地铁线、站点、乘客的事件直接生成音符，整体刻意克制、轻。人多时也不全放：例子里一次来七个以上乘客只放前七个，按 1/16 音符错开排着响。这和 Bloom 的极简气质最接近。
  来源：https://designingsound.org/2016/02/18/the-programmed-music-of-mini-metro-interview-with-rich-vreeland-disasterpeace
- **Tetris Effect**：方块落地、消行都触发「点缀音」（stinger），用的是当前关卡音乐里的乐器，所以操作本身就在给音乐加花；消行越多，点缀越丰富。（我没找到它把音效对齐节拍的一手资料，这点不下结论。）
  来源：https://www.gamedeveloper.com/audio/game-audio-analysis---tetris-effect

**要点**：
- 所有工具的免费版基本都不能商用（ElevenLabs 音效带署名是例外）。打算发出去的素材，**在付费那个月里生成**，并留截图（生成日期 + 当时的订阅）。
- 没有哪家能保证「准确在某个调、正好能无缝循环」。调和循环点都要拿到后再处理，这部分 AI（我）能用 ffmpeg 等工具做。
- 音效类工具出来的是固定音高的采样，「连锁升调」还是要靠游戏里变调或合成。

### 不用 AI 的备选
- **代码合成（推荐给 Bloom 的「啵」）**：Bloom 要的音很简单（正弦 / 轻 FM + 快起音 + 指数衰减），我可以在 C# 里写合成器，游戏启动时把每个音阶音预先算成 AudioClip。好处：音高天然准确、任何音高音色都一样、零授权风险、不花钱。
  - **网页版的坑**：Unity 网页版不支持 `OnAudioFilterRead` 这种实时合成，混音器也只有音量能用、效果器都不能用；但 `AudioClip.Create`（关掉 Stream）可以用，所以要「启动时预先算好」，不能边玩边算。BGM 压低也要用脚本调音量。浏览器要等玩家第一次点击才放声音，Bloom 一开始就要点，正好。循环音乐导出成 AAC 时开头约 1024 个采样可能出杂音，循环 BGM 要留一点开头静音。
    来源：https://docs.unity.com/en-us/engine/6000.3/manual/platform-specific/webgl/develop/audio
- **Kenney 音效包**（kenney.nl，CC0，可商用、不用署名）：界面点击、按钮类音效现成可用。
- **Freesound**（freesound.org）：量大，但授权混杂（CC0 / CC-BY / CC-BY-NC），**只筛 CC0**，或者记下署名。

## 三、给 Bloom 的推荐流程

1. **设计师先定方向（约半小时）**：找 3–5 个「想要这种感觉」的参考（游戏片段或曲子，只用来听、不上传给 AI），用一句话描述，比如「像在安静的房间里敲玻璃杯」。再定 BGM 要不要有和弦变化（建议不要，铺底就好）。
2. **音效：先用代码合成**：我写 3–4 种「啵」的音色候选（玻璃钟、卡林巴、柔和正弦、木琴），按五声音阶、随连锁升调，连同发声数上限、合并、BGM 压低一起做进游戏。做一个试听小场景，设计师挑最喜欢的一种。
3. **合成不够好听再用 ElevenLabs 音效**（订 Starter 一个月 $6）：设计师按我写好的提示词生成十来条、挑 2–3 条，我来处理成同一个音、裁好、按音阶变调接进游戏。按钮、过关等界面音同样可以用这里或 Kenney 的。
4. **BGM 用 Suno Pro 一个月（$10）**：我写提示词（纯音乐、极简氛围、D 大调五声、72 BPM、钢琴 / 铺底、无鼓）；设计师生成一批、挑 2–3 首最喜欢的。想要「更干净可控」的备选就用 ElevenLabs 音乐（独立游戏可商用）。
5. **我来做后期**：验调、必要时移调、找循环点做无缝循环、统一响度、导出 Unity 能用的格式；音效音阶对齐 BGM 的调。
6. **设计师试玩把关**：只听三件事：大连锁时吵不吵、BGM 会不会腻、音效和音乐配不配。有问题说感受，我来调参数。
7. **留授权凭证**：生成时的订阅截图、日期、工具名记到文档里，之后发布要用。
