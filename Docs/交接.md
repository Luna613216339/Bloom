## 怎么试玩

1. 打开 Unity，打开 `Assets/Scene/MainMenu.unity`，按 Play，从格子里选关。编辑器里全部关卡默认都能选（Tools → Bloom → Editor: All Levels Selectable 可以关掉看真实解锁）。
2. 每次 Play 自动重置进度并发 300 块测试钱，所以续命按钮（没过关时结算面板上的「再打一下 + 价钱」）按得起。最省事的试法：第 3 关故意点一块空地（什么都不会着），结算面板上就有「再打一下」，按了再点中心。注意 14 回火、16 硬壳是解谜关，按现在的规则**不给续命**，面板上没有这个按钮；13、15、17 有。
3. 卡住了翻 `Docs/关卡表.md` 的「解法」列。

- 命令行编译通过，macOS 包打得出来。

### 3. 要你判断的
- 分裂球 / 硬球 / 联动门 / 续命 四样新东西要不要进正式序列（各自的样关在 13–17）。
- 续命和解谜关的冲突：现在解谜关不给续命。备选：(a) 维持；(b) 解谜关也给但更贵；(c) 全部给，但解谜关续过的不算"完美通关"。
- 续命占位价 60 / 30、一次尝试最多续一次。另外正式关卡的 HUD 现在不显示钱包余额，续命按钮上却标着价钱，玩家不知道买不买得起 —— 要不要在正式关卡也显示余额。
